# How to Use This Skill

Hey Codex, I just added the "hyper-intensive-markdown" skill. I need a one-shot component extraction pack with a migration guide and a sketch wireframe diagram.

## Example Invocations

**Example 1:**
Hey Codex, I just added the "hyper-intensive-markdown" skill. Extract the Property Verification Card into its own module and provide a migration guide and wireframe.

**Example 2:**
Hey Codex, I just added the "hyper-intensive-markdown" skill. Create a component extraction plan and migration guide for the Payments Summary panel, plus a wireframe.

**Example 3:**
Hey Codex, I just added the "hyper-intensive-markdown" skill. One-shot a full extraction pack for the Search Filters drawer and call out risks.

## What to Provide

- Component or feature name
- Current location and ownership
- Target location or module
- Dependencies and APIs
- Known risks or constraints

## What You'll Get

- Structured extraction plan
- Migration guide with API mapping
- Wireframe sketch (Mermaid)
- Risks and open questions
